## ✨ Overview

**Ecosystem.design** is a futuristic AI-powered interior design platform delivering immersive inspiration, intelligent design assistance, responsive experiences, and premium motion-driven interfaces.

## 🚀 Highlights

- AI Interior Designer
- Interactive Design Gallery
- Authentication
- Booking & Contact
- Pricing Plans
- Testimonials
- Responsive UI
- Smooth Framer Motion animations
- Supabase backend
- Modern component architecture

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React + TypeScript |
| Build | Vite |
| Styling | Tailwind CSS |
| Animation | Framer Motion |
| Icons | Lucide React |

```bash

cd Ecosystem-InteriorDesign
npm install
npm run dev
```
